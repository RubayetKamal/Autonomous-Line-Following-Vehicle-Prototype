# Autonomous Line-Following Vehicle (AVR328P Project)

**Grade: 1,3**

This project involved developing a fully autonomous vehicle prototype using an AVR328P (Arduino Uno), capable of navigating a track independently while responding to environmental cues such as lines, colors, and obstacles.

## Highlights

- 🤝 Collaborated on system design and implementation as part of a team project.
- 🔄 Developed a finite state machine in C using the Arduino library to control vehicle behavior.
- 📍 Integrated a line sensor with an L298N motor driver to enable movement based on line detection.
- 🏎️ Optimized vehicle speed and control to handle a variety of track layouts, including 90° turns, ovals, and figure-eight shapes.
- 📡 Integrated the HC-SR04 ultrasonic sensor for real-time obstacle detection and evaluation.
- 🛠️ Designed and fabricated 2D/3D parts using SolidWorks/Fusion 360, with materials such as PLA and wood, based on collaborative planning.
- 🎨 Calibrated the TCS3200 color sensor to detect specific surroundings and trigger actions like parking or route changes based on detected color.
- 🧩 Modeled the system using SysML after thoroughly analyzing project goals and requirements.

🏆 **Awarded for implementing the most features involving color detection.**
